Solche 기능 가이드

궁금한 항목을 누르면 자세한 설명과 실제 앱 화면을 볼 수 있어요. 스크린샷은 iPhone 기준이지만 다른 기기에서도 똑같이 쓸 수 있습니다.

글쓰기

글 올리기

화면 맨 위의 메모를 입력하세요 칸에 글을 적고 오른쪽 위 저장을 누르면 타임라인 맨 위에 톡 올라갑니다. 엔터로 나눈 줄바꿈도 그대로 예쁘게 남아요.

글마다 언제 적었는지 시간이 함께 찍혀요. 방금 적은 글은 "방금 전", "5분 전"처럼 친근하게, 며칠 지난 글은 "어제", "금요일"처럼 한눈에 들어오게 보여 줍니다.

사진 붙이기

상단 바의 사진 아이콘을 눌러 사진을 골라 보세요. 글 하나에 최대 10장까지 거뜬히 들어갑니다. 글 없이 사진만 툭 올려도 좋고, 이야기와 함께 남겨도 좋아요.

예전 글 돌아보기

스크롤을 쭉 내리면 예전에 적었던 글들이 끊김 없이 스르륵 이어서 불러와집니다.

글 다루기

답글 달기

글 오른쪽의 답글 아이콘(굽은 화살표)을 누르면 원본 글을 보면서 바로 밑에 생각을 덧붙일 수 있어요. 처음 적은 생각을 이어 가거나 나중에 후기를 남길 때 딱이에요.

스레드로 보기

답글은 원래 글 아래에 세로선으로 나란히 묶여서, 생각이 어떻게 흘러갔는지 한눈에 읽힙니다. 물론 답글에 또 답글을 달 수도 있어요!

맨 위에 고정하기

압정 모양 버튼을 콕 누르면 해당 글이 타임라인 꼭대기에 고정됩니다. 다시 한 번 누르면 언제든 고정이 풀려요.

고정해 둔 글이 여러 개라면 원하는 순서로 줄을 세울 수도 있어요. 휴대폰에선 글을 꾹 눌러서 끌고, 컴퓨터에선 마우스로 바로 끌어다 놓으면 됩니다.

수정, 복사, 삭제

각 글 오른쪽 위에 나란히 있는 작은 버튼들을 써 보세요. 연필은 수정, 겹친 네모는 텍스트 복사, 휴지통은 삭제입니다. 실수로 지우지 않도록 삭제할 땐 한 번 더 물어봐요.

사진 보기

사진 크게 보기

타임라인에 올린 사진을 터치하면 화면 가득 시원하게 열려요. 두 손가락으로 확대해 자세히 보거나, 옆으로 넘겨 가며 같은 글에 묶인 사진들을 감상해 보세요.

컴퓨터에서는 키보드 방향키(← →)로 편하게 사진을 넘기고, Esc 키 하나로 바로 닫을 수 있습니다.

찾기와 정리

검색

상단 돋보기 버튼을 누르고 기억나는 단어를 쳐 보세요. 그 단어가 담긴 글만 쏙 골라 보여 주고, X를 누르면 원래 타임라인으로 돌아옵니다.

메뉴와 폴더

왼쪽 위 메뉴(≡)를 열면 내가 만든 폴더 목록과 각 폴더에 담긴 글 개수가 한눈에 보여요. 원하는 폴더를 누르면 바로 그 폴더의 타임라인으로 이동하고, 새로 쓰는 글도 그 폴더에 착착 쌓입니다.

폴더 만들기와 관리

폴더 생성으로 새 방을 만들고, 폴더 관리에서 언제든 이름을 고치거나 정리할 수 있어요.

혹시 폴더를 지우더라도 그 안에 있던 소중한 글들은 날아가지 않고 기본 폴더로 안전하게 이사하니 걱정 마세요. (기본 폴더 자체는 지워지지 않아요.)

프로필

프로필 사진과 이름

메뉴 → 프로필 수정에서 내 마음에 드는 프로필 사진과 이름을 설정해 보세요. 타임라인의 모든 글에 내 프로필이 귀엽게 함께 표시됩니다.

프로필 숨기기

프로필 아이콘 표시 스위치를 끄면 동그란 프로필 영역이 사라지면서 본문 영역이 훨씬 넓어져요. 데스크톱에서 창을 좁게 띄워 놓고 쓸 때 특히 추천하는 설정입니다!

꾸미기

설정 화면

상단 톱니바퀴 아이콘이나 메뉴 → 설정으로 들어가면 글자 크기, 다크 모드, 언어, 배경색을 내 취향대로 바꾸고 데이터 백업·복구까지 챙길 수 있습니다.

다크 모드

상단 막대의 달 모양 버튼을 누르면 차분한 다크 모드로, 해 모양 버튼을 누르면 다시 환한 낮 화면으로 즉시 바뀝니다.

글자 크기와 줄 간격

글자 크기 조절에서 슬라이더를 좌우로 밀어 내 눈에 가장 편안한 크기를 찾아보세요. 미리보기 문장으로 느낌을 즉시 확인할 수 있어요.

줄 간격도 좁게, 보통, 넓게 세 단계 중에서 고를 수 있어요.

배경색

배경색 조절에서 마음에 드는 색감을 직접 찍거나 R·G·B 숫자를 입력해 보세요. 내가 고른 배경 톤에 맞춰 버튼과 이름 색상까지 조화롭게 맞춰집니다.

11개 언어

처음 실행하면 기기 언어를 알아서 따라가고, 설정의 언어 선택에서 11개 언어 중 원하는 언어로 언제든 바꿀 수 있어요.

English, 한국어, 日本語, 简体中文, 繁體中文, Español, Português, Français, Deutsch, Bahasa Indonesia, Русский

백업과 복구

데이터 백업

설정 → 데이터 백업을 누르면 지금까지 쓴 모든 글, 사진, 폴더, 설정값이 파일 하나로 깔끔하게 묶여 저장됩니다. 저장할 위치도 직접 고를 수 있어요. 앱을 지우거나 기기를 바꾸기 전엔 잊지 말고 꼭 백업해 주세요!

데이터 복구

설정 → 데이터 복구에서 보관해 둔 백업 파일을 선택하면 그 시절의 타임라인과 설정으로 그대로 돌아갑니다. 현재 기기에 있던 내용은 백업 파일 내용으로 덮어써지니, 지금 글도 남기고 싶다면 복구 전에 먼저 백업해 두세요.

만약 정상적인 Solche 백업 파일이 아니면 알아서 복구를 멈추고 기존 데이터를 안전하게 지킵니다.

마지막 복원 되돌리기

복구를 마친 직후에는 설정 화면에 마지막 복원 되돌리기 버튼이 생겨요. 혹시 옛날 백업 파일을 잘못 골랐더라도 당황하지 않고 복구 직전 상태로 단숨에 되돌릴 수 있습니다.

새 기기로 옮기기

쓰던 기기에서 백업 파일을 만든 뒤, 메일이나 클라우드 드라이브, USB 등 편한 방법으로 새 기기에 파일을 옮겨서 복구만 누르면 이사 끝입니다.

내 기기 속 어느 경로에 데이터가 저장되고 있는지는 메뉴 → 이 앱에 관하여에서 투명하게 확인하실 수 있어요.

자주 묻는 질문

인터넷이 안 되는 곳에서도 쓸 수 있나요?

물론이죠! Solche는 인터넷에 아예 연결하지 않는 앱이라 비행기 안이나 데이터가 끊긴 곳에서도 평소와 똑같이 쾌적하게 쓸 수 있습니다.

내 글을 누가 볼 수 있나요?

오직 나 혼자만 볼 수 있습니다. 모든 글과 사진은 내 기기 안에만 저장되고 외부 서버로 전송되는 일이 절대 없거든요. 계정 자체가 없으니 비밀번호가 털릴 걱정도 없습니다.

휴대폰과 컴퓨터가 자동으로 동기화되나요?

아니요, 서버를 두지 않는 구조라 기기 간 자동 동기화는 지원하지 않습니다. 대신 기기를 옮기실 때는 백업 파일 하나로 사진과 설정까지 통째로 옮기실 수 있어요.

앱을 지우면 글도 사라지나요?

네, 모든 데이터가 서버가 아닌 앱 내부에만 저장되기 때문에 앱을 삭제하면 글도 함께 지워집니다. 앱을 지우거나 폰을 바꾸실 땐 꼭 먼저 백업 파일을 만들어 두세요!

무료인가요?

네! 처음부터 끝까지 무료이고, 글을 읽는 흐름을 방해하는 광고도 일절 없습니다.

쓰다가 버그를 발견했거나 건의하고 싶은 아이디어가 있어요!
